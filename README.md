🧠 Cheat-Code
A daily DSA practice repository for mastering Data Structures & Algorithms through consistent problem solving.







📌 About
Cheat-Code is my daily Data Structures & Algorithms practice repository.

The goal is simple:

Solve → Understand → Implement → Repeat.

This repository contains solutions to a broad range of coding problems, organized into individual problem folders. Each solution focuses on a practical algorithmic pattern and is written with interview preparation, readability, and reusable problem-solving techniques in mind.

The repository is continuously expanded as I work through more problems.

🎯 Objectives
Build strong DSA fundamentals.

Improve algorithmic problem-solving skills.

Practice writing clean and efficient code.

Recognize common interview patterns quickly.

Strengthen Python problem-solving skills.

Build consistency through daily practice.

Maintain a searchable personal reference for revision.

🧠 Core Interview Patterns
One of the main purposes of this repository is to recognize patterns rather than memorize isolated solutions.

Some recurring patterns include:

Sliding Window
Used for substring, subarray, and frequency-window problems.

Expand → Validate → Shrink → Record
Two Pointers
Useful for sorted arrays, linked lists, and string traversal.

Left → ← → Right
Monotonic Stack
Useful for next-greater-element and range-based problems.

Maintain a stack with monotonic ordering
Binary Search on Answer
Useful when the answer lies within a monotonic search space.

Minimum answer ← search space → Maximum answer

📈 Practice Philosophy
This repository follows a simple progression:

Learn the pattern
       ↓
Solve the problem
       ↓
Write the solution
       ↓
Test edge cases
       ↓
Review complexity
       ↓
Move to the next problem
The focus is not only on obtaining the correct answer, but on becoming faster at identifying the underlying technique.

🔁 Revision Workflow
For revision, problems can be revisited by pattern instead of only by problem number.

For example:

Need Sliding Window practice?
→ Review all Sliding Window problems.

Need Tree DFS practice?
→ Review Tree DFS problems.

Need Monotonic Stack practice?
→ Review stack-based problems.

Need DP practice?
→ Review the Dynamic Programming problems.
This makes the repository useful as both a practice log and a technical interview revision resource.

💻 Running the Solutions
Clone the repository:

git clone https://github.com/anurag-rvnkr1/Cheat-Code.git
cd Cheat-Code
Open any problem directory and run the relevant Python file:

python solution.py
For SQL problems, execute the query against the corresponding LeetCode-style schema.

Many LeetCode problems provide platform-specific classes or APIs such as TreeNode, ListNode, Robot, guess(), or rand7(). Those definitions may already be provided by LeetCode and are sometimes represented as placeholders inside the repository solutions.
